{{- if include "github-sts.hasPooledApp" . }}

App pools are configured:
{{- range $appName, $app := .Values.github.apps }}
{{- if $app.instances }}
{{- $strategy := (($app.rotation | default dict).strategy) | default "round_robin" }}
  - {{ $appName }}: {{ len $app.instances }} GitHub App instance(s), rotation
    strategy "{{ $strategy }}"
{{- if eq $strategy "rate_limit_aware" }}
    NOTE: rate_limit_aware is accepted but not yet implemented server-side; this
    pool behaves like round_robin and the server logs a warning at startup.
{{- end }}
{{- end }}
{{- end }}
  Every instance in a pool must be installed with identical permissions and
  repository access. A mismatched instance surfaces only as intermittent 422s.
  Requires a github-sts image that knows instances:, meaning 0.1.1 or later,
  which is what this chart's appVersion pins. An older image rejects the key and
  the pod CrashLoopBackOffs with "field instances not found in type
  config.AppConfig". It does not fall back to the flat form.
  Alert on githubsts_app_pool_exhausted_total: it fires when every instance in
  a pool failed one request.
{{- end }}

  WARNING: a NetworkPolicy is rendered for this release and egress is
  default-deny, so spans will be dropped with no error anywhere until you allow
  egress to the collector. The chart cannot derive the rule — a DNS name does
  not tell it the collector's pod labels. Add one under
{{- if .Values.networkPolicy.native.enabled }}
    networkPolicy.native.extraEgress:
      - to:
          - namespaceSelector:
              matchLabels:
                kubernetes.io/metadata.name: observability
        ports:
          - port: {{ ternary 4318 4317 (hasPrefix "http" (.Values.tracing.protocol | default "grpc" | toString | lower)) }}
            protocol: TCP

{{- if .Values.networkPolicy.cilium.enabled }}
    networkPolicy.cilium.extraEgress:
      - toEndpoints:
          - matchLabels:
              io.kubernetes.pod.namespace: observability
        toPorts:
          - ports:
              - port: "{{ ternary 4318 4317 (hasPrefix "http" (.Values.tracing.protocol | default "grpc" | toString | lower)) }}"
